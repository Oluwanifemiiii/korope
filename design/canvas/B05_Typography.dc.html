Rules

  • Weights 400, 500, 600, 700 only. Load exactly these four.
  • Every fare, time, ETA, countdown and seat number uses tabular-nums so digits never jump.
  • Nothing below 12 px. Labels at 12 px are 500 or heavier.
  • Naira is written ₦1,500: no space, comma thousands, no kobo unless non-zero.
  • Sizes in rem from these px values so Android font scaling works.
